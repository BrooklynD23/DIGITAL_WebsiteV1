1 · Home hero

The drawing opens with a transform. Layout no longer moves.

Before, the art box animated top/bottom for 600ms, so each frame was a layout shift. Now the box sits at its opened size and the first-viewport position is a translate + scale, measured by HeroStages. Same 600ms, same --r2-ease-emphasized, same end states.

4 · Column offset

Page content lines up with the DIGITAL wordmark.

.wrap was 1024px inside a padded section, so content sat a gutter left of the nav. It is now calc(1024px - 2 * var(--r2-gutter)), the nav's content edge. Below 1024px nothing changes.
