# Recurse Center — https://www.recurse.com
Category: builder community / programmer retreat. Why: the clearest "who it's for + how it works" explanation of any site scouted; people-first photography, near-zero chrome. Pick reason: closest model for a self-directed builder community.
Capture: standalone headless Chromium (shared MCP browser was down), desktop + mobile + 2 scroll shots in design-lab/references/recurse-center/.

## Narrative (homepage)
1. Hero statement with two-tone H1 (brand name in accent green, claim in bold) + 3 candid workspace photos, then one pill CTA
2. "Rediscover the joy" retreat overview (short paragraphs, light-weight H2)
3. Dedicated time / community / lightweight structure (weekly 5-min presentations, named batch events)
4. Single large pull-quote with member photo + batch label ("Summer 2, 2023")
5. Recruiting (companies as employment destinations; business model stated plainly)
6. Alums / partner logos, repeated Apply CTA
## Type
InterVariable only. H1 54px/700, ls -1.1px. H2 32px/200 (light, large, quiet). Body 16/25.6. Colour rgb(42,45,45) on white.
## Color
White bg, near-black text, ONE green accent (CTA + brand line + inline links), purple only for the quote attribution + highlighter-yellow underlay on the key clause.
## Layout / density
Wide photo strip (edge-to-edge, 16px gutters) then narrow ~560px reading column. Generous whitespace, almost no cards. Page height ~5100px.
## Motion
None observed in static capture (not verified).
## Project/people/CTA patterns
- No project grid: proof = named alumni quotes with real faces + counts of alumni. Apply CTA in nav, hero, footer (green pill, sticky nav button).
- Partner language: companies framed as hiring destinations, funding model disclosed ("free because companies pay for placements").
- Mission rhetoric: autonomy + joy + rigor-at-the-edge, "never graduate"; no hype adjectives.
## Mobile: single column, same type scale; nav collapses.
## Steal as principle
1. Explain the mechanism (weekly cadence, named rituals) instead of adjectives.
2. Disclose how the org is funded; trust through plain business statements.
3. Highlighter underlay on the one clause that matters in a pull-quote.
## Avoid
1. Zero projects shown: DIGITAL must lead with work. 2. Light H2 weight over long pages reads washed out. 3. Generic stock-feel group photos if we can't shoot real ones.
## Tech observed
No gsap/THREE/Lenis globals; FontAwesome + InterVariable.
