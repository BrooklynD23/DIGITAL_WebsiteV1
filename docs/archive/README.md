# Archived Documentation

These files are **historical** — they record planning sessions, handoffs, and superseded
design decisions. They are kept for traceability but are **not authoritative** for current
development.

For current guidance, start at [`docs/README.md`](../README.md).

## What belongs here

| Archive path | Original purpose | Superseded by |
|--------------|------------------|---------------|
| `handoffs/` | Agent handoff notes from mid-build sessions | Current routes + `docs/ROUTES.md` |
| `plans/` | UI revamp and Codex delegation plans | `DESIGN.md`, route-scoped `docs/design/*.DESIGN.md` |
| `specs/` | Approved specs that have been implemented | `docs/design/BRAND.md`, route design docs, shipped code |
