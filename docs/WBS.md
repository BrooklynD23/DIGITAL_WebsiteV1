# Standardized WBS Task Pipeline

Date: 2026-11-17. Source: the project manager lead. Every project follows this pipeline.

| # | Task | What it does |
|---|---|---|
| 1 | Problem Definition & Requirements | Define hard dimensional targets and limitations. |
| 2 | Mechanism Case Study | Reverse-engineer real-world consumer mechanisms. |
| 3 | Material & Process Analysis | Evaluate materials and manufacturing methods. |
| 4 | Decision Matrix | Use a weighted trade matrix to finalize the mechanism concept. |
| 5 | CAD & GD&T | Draft 3D models with strict tolerance stack-ups and internal cable routing. |
| 6 | FEA Simulation | Run structural and thermal Finite Element Analysis to validate physics. |
| 7 | Prototyping & CAM | Program CAM toolpaths and fabricate high-fidelity physical mockups. |
| 8 | Testing & TDP Hand-off | Run cycle tests and deliver 2D drawings with a Bill of Materials. |

## Stages on the home page

The home hero groups the eight tasks into four stages of two tasks each.

| Stage | Tasks |
|---|---|
| 01 Discover | 1, 2 |
| 02 Decide | 3, 4 |
| 03 Design | 5, 6 |
| 04 Build | 7, 8 |

## Project manager on Tasks 1-2

> "The first focuses on Discovery of what you are designing. If that's a haptic engine module, you do research into what a haptic engine module does, what it's used for from a consumer's perspective, and how it fits into the entire project, etc. The second dives into how it works as a standalone device and explores existing designs that were created by real people in industry."
